The website stores its production assets locally so deployments do not depend on third-party image CDNs.

## Final brand system

The approved logo is option 01: a white **A** held inside a Deep Teal **D**. The compact mark and the horizontal lockups use the same geometry.

- `design-proposals/logo-option-01-a-within-d.svg`
- `design-proposals/logo-option-01-a-within-d.png`
- `public/adaptance-logo.svg`: horizontal lockup for light backgrounds
- `public/adaptance-logo-light.svg`: horizontal lockup for dark backgrounds
- `public/adaptance-mark.svg`: scalable square mark
- `public/adaptance-mark-512.png`: 512 × 512 app icon
- `public/favicon.svg`: browser icon

Earlier explorations remain in `design-proposals/` as decision history. They are not production logos.
